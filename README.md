# MobiMon

MobiMon brings a friendly companion to your car. Spend time with Mobi the dog or
Luna the cat, check vehicle status, chat while parked, and complete quests to
earn points for outfits and accessories.

The app is currently in development.

Start with [Contributing](.github/CONTRIBUTING.md) for setup and required checks.
The [module map](docs/ARCHITECTURE.md#target-modules-and-dependencies) identifies
the Quest, AI, Companion (Shop/Home/Settings), and Vehicle workspaces. Follow the
[parallel workflow](.github/CONTRIBUTING.md#parallel-feature-development) and use
the [Compose library](docs/DESIGN.md#reusable-compose-library-and-asset-handoff)
when migrating screens to the current Figma design.
