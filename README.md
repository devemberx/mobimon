# MobiMon

MobiMon is an Android companion app. A small companion helps
the user understand vehicle status, complete care quests, and build persistent
progress through calm, focused interactions.

The current foundation provides companion and vehicle home surfaces, appearance
and display preferences, simulated vehicle data for Debug builds, and a persistent
first quest with an exactly-once XP reward. Release builds report vehicle data as
unavailable until a verified real adapter is connected. Real AI conversation,
additional quests, and a system overlay are not implemented yet.
